SET @old_filial := 1719;  -- 👈 filial antiga
SET @new_filial := 676;   -- 👈 filial nova
SET @schema := 'boomsistemas'; -- 👈 banco de dados

-- Ajuste para permitir concatenação longa, caso haja muitas tabelas
SET SESSION group_concat_max_len = 1000000;

-- Gerar SELECTs
SELECT GROUP_CONCAT(
    CONCAT('SELECT * FROM ', TABLE_SCHEMA, '.', TABLE_NAME, ' WHERE filial_id = ', @old_filial, ';')
    SEPARATOR '\n'
) AS selects
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_SCHEMA = @schema
  AND COLUMN_NAME = 'filial_id';

-- Gerar UPDATEs
SELECT GROUP_CONCAT(
    CONCAT('UPDATE ', TABLE_SCHEMA, '.', TABLE_NAME,
           ' SET filial_id = ', @new_filial,
           ' WHERE filial_id = ', @old_filial, ';')
    SEPARATOR '\n'
) AS updates
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_SCHEMA = @schema
  AND COLUMN_NAME = 'filial_id';


🧩 Script: Geração automática de SELECTs e UPDATEs para unificação de filiais

📘 Descrição

Este script SQL foi criado para auxiliar na unificação de filiais dentro do banco de dados, permitindo identificar e atualizar todos os registros relacionados a uma filial antiga (@old_filial) para uma nova filial (@new_filial), de forma automatizada e segura.
 

⚙️ Funcionamento

Definição de variáveis principais:

@old_filial: ID da filial antiga que será substituída.

@new_filial: ID da filial nova que substituirá a antiga.

@schema: Nome do banco de dados onde a busca será realizada.

Ajuste de configuração:

O comando SET SESSION group_concat_max_len = 1000000; aumenta o limite do GROUP_CONCAT, garantindo que o resultado não seja truncado, mesmo que existam muitas tabelas com o campo filial_id.

Geração de comandos SELECT:

A primeira consulta percorre todas as tabelas do schema informado que possuem a coluna filial_id.

Para cada uma delas, gera um comando SELECT * FROM tabela WHERE filial_id = @old_filial;

Isso permite verificar previamente quais registros seriam afetados antes de executar qualquer atualização.

Geração de comandos UPDATE:

A segunda consulta cria automaticamente os comandos UPDATE para todas as tabelas que possuem o campo filial_id.

Cada comando atualiza o valor de filial_id de @old_filial para @new_filial.

💡 Utilidade

Unificação de filiais: facilita o processo quando há necessidade de consolidar registros de duas filiais em uma só (ex: após fusões, reorganizações ou encerramentos).

Automação: evita a necessidade de procurar manualmente todas as tabelas relacionadas.

Segurança: possibilita gerar os SELECTs primeiro para revisão antes de aplicar os UPDATEs.
 

⚠️ Recomendações

Sempre executar os SELECTs primeiro para confirmar quais registros serão impactados.

Realizar backup completo do banco antes de aplicar os UPDATEs.

Ideal para ambientes de manutenção, migração ou auditoria.
