🧠 Mini Tutorial — Integração com API Carchat

A classe CarChat serve pra se conectar à API de Integração de Leads da Carchat (https://api.carchat.com.br/).

Ela já usa o GuzzleHttpV7\Client pra fazer requisições HTTP com segurança e timeout controlado.
 

⚙️ Como funciona

Estrutura principal:

A classe possui dois métodos principais:

  1. ativarLoja(array $params)

Endpoint: POST /lojas/ativar

  • Objetivo: registrar ou ativar uma loja na Carchat.
  • Retorno: um token (carchat_loja_token) usado nas próximas requisições (como o envio de leads).
  • enviarLead(string $xAuthToken, array $leadData)

 

Endpoint: POST /leads/

  • Objetivo: enviar informações de um lead para a loja correspondente.
  • Requer o X-Auth-Token obtido no passo anterior (ativarLoja).

 

🧩 Requisitos

  • PHP 7.4+
  • Dependência: "guzzlehttp/guzzle": "^7.0"
  • Endpoint base já configurado:

 

  public const API_BASEURL = "https://api.carchat.com.br/";

🚀 Exemplo de uso prático

1️⃣ Ativar ou registrar uma loja

Exemplo de chamada:

 

use Application\Libraries\CarChat;

$carchat = new CarChat();

$params = [
  "usuario" => "testeuser",
  "senha" => "123456",
  "nome_loja" => "Minha Loja Teste",
  "cnpj" => "12345678000190",
  "store_token" => "teste123",
  "origin_crm" => "use-bruno",
  "urlFeed" => null
];

$response = $carchat->ativarLoja($params);

print_r($response);

Resposta esperada (sucesso):

 

{
  "success": true,
  "data": {
    "carchat_loja_token": "eyJhbGciOiJIUzI..."
  }
}

Esse token (carchat_loja_token) será usado no método enviarLead() como X-Auth-Token.

2️⃣ Enviar um lead

 

$xAuthToken = "eyJhbGciOiJIUzIUz..."; // Token retornado no passo anterior

$leadData = [
  "store_token" => "teste123",
  "lead" => [
    "nome_cliente" => "Bruno Costa",
    "numero_cliente" => "11999999999",
    "email_cliente" => "bruno@teste.com",
    "portal" => "OLX",
    "veiculo_interesse" => [
      [
        "id" => "123",
        "marca" => "Chevrolet",
        "modelo" => "Onix",
        "cor" => "Prata",
        "ano" => 2023
      ]
    ]
  ]
];

$response = $carchat->enviarLead($xAuthToken, $leadData);

print_r($response);

Resposta esperada (sucesso):

 

{
  "success": true,
  "statusCode": 201,
  "data": { ... lead salvo ... }
}

🧪 Testes — Endpoint use-bruno

Você pode testar diretamente esses endpoints no projeto use-bruno.

➡️ Basta ativar a rota de teste existente lá que consome o CarChat:

 

$carChat = new \Application\Libraries\CarChat();

// Teste de ativação
dd($carChat->ativarLoja([...]));

// Teste de lead
dd($carChat->enviarLead($token, [...]));

Ou, se preferir, usar ferramentas como Bruno (cliente REST open-source inspirado no Postman) pra testar os endpoints diretamente:

  • Endpoint: https://api.carchat.com.br/lojas/ativar
  • Endpoint: https://api.carchat.com.br/leads/
  • Exemplo de payload: disponível no código acima

📘 A documentação oficial da API também lista todas as propriedades e exemplos de payloads completos:

👉 https://api.carchat.com.br/docs#/
 

🧾 Dica extra

  • O método fireGuzzle() já converte os dados enviados para JSON se você passar $isJson = true.
  • Todos os retornos são arrays associativos, prontos para serem interpretados no backend.
  • As exceções são capturadas e logadas via handleException() ou handleLog() (já tratadas no código).
